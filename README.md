## 🌟 核心理念与功能特性

1. **双账分离架构（计划 vs 真实）**
   - **计划账（预案）**：设定总投入预算 $P$，正/倒金字塔分批建仓推演，未成交层差额自动转化为可用余额。
   - **真实账（交割）**：只读锁定底仓成本，免 API 打通券商接口（保护持仓隐私），仅需抄入实扣划转金额，系统自动倒推规费与实盘滑点，校准真实加权成本（WAC）。
2. **AI 6维研判与标准化四段收敛（离线协同）**
   - 团队研判提示词生成器（技术面、基本面、消息面、同业对标、Why Box 核心逻辑）。
   - 复制提示词直接发给任意外部大模型（DeepSeek / 豆包 / ChatGPT），粘贴回复即可秒级标准化解析为：**① 向下接档 ｜ ② 向上跟进档 ｜ ③ 硬失效止损 ｜ ④ 阶梯止盈**。
   - 占预算比例自动校验严格 $= 100\%$，一键套用为执行挂单。
3. **今日裁决横幅与现实事件闸门 (Verdict & Gates)**
   - 盘中竞速比对（现价 vs 挂单价）：到价放行、未到价等待伏击。
   - **A/B 分支硬纪律**：分支 B（成长股现价跌破失效线一律强制 Ban 买入、破位次日全清）vs 分支 A（高股息仅告警重估，不设价格止损）。
   - **事件闸门系统**：Unlock（过户到账前冻结）、Kill（业绩变脸/突发黑天鹅一票否决熔断）、Review（季报到期复盘）。
4. **离场三结局剧本**
   - 这一单只许三种结局：**① 止损离场 ｜ ② 保本离场（随行情上移锁利） ｜ ③ 止盈剧本**，到价按剧本执行，杜绝临时起意加戏。
5. **数据主权 100% 自持**
   - **一键导出备份 (JSON)**：生成完整包含所有股票、批次、日志、快照的加密/明文 JSON 备份。
   - **一键恢复导入 (JSON)**：跨设备迁移、换机冷备秒级导入。
   - **一键彻底清空 / 恢复示例**：支持一键清空全部自填数据恢复出厂，或载入标准示例学习。

## 🚀 部署与使用方式

### 方式 A：GitHub Pages 免费在线托管（最推荐，多端随时开）

1. 在 GitHub 上 Fork 或新建一个代码仓库（Repository）。
2. 将仓库中的 `index.html` 提交至根目录。
3. 进入仓库设置 **Settings** ➔ **Pages** ➔ **Build and deployment**：
   - Source: 选择 `Deploy from a branch`。
   - Branch: 选择 `main` (或 `master`) / `/ (root)`，点击 **Save**。
4. 稍等 1 分钟即可获得您的专属专属访问网址：`https://<你的用户名>.github.io/<仓库名>/`。
5. **添加到手机桌面（PWA 体验）**：
   - **iPhone (Safari)**：打开页面 ➔ 点击底部「分享」按钮 ➔ 选择 **「添加到主屏幕」**。
   - **Android (Chrome)**：点击右上角菜单 ➔ 选择 **「安装应用」** 或 **「添加到主屏幕」**。
   - 即可获得与原生 App 无异的独立全屏体验，无浏览器地址栏与工具条。

### 方式 B：本地双击直接运行（断网也能用）

- 将 `index.html` 下载到电脑或手机「文件」中，双击任意浏览器即可打开使用。

### 方式 C：苹果手机（巨魔 TrollStore）极客本地回环运行

- 将 `index.html` 放入手机文件夹，使用 iSH Shell / a-Shell 运行 `python3 -m http.server 8080`，Safari 访问 `http://127.0.0.1:8080` 并添加到主屏幕，享受最极致的单机断网体验。
