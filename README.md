## 💎 5 大实战走不通痛点彻底治理矩阵 (Architectural Rectification)

| 痛点编号 | 原先实战致命缺陷 | 终极系统架构治理闭环 (Architectural Rectification) |
| :--- | :--- | :--- |
| **痛点 1** | **一笔成交消耗多档预案**<br>（盘中脉冲暴跌一笔吃透 2 档，原系统只能核销一层，另一层死挂导致数据打架） | **引入多档消费聚合器 (`consumeBatches`)**：<br>在录入实扣流水时，输入交割总股数（如 1,200 股），系统自动从最接近现价的挂单层向下逐档吞吐（档位1吃满 700 股，档位2吃满 500 股）；两层统一标记 `exec.matched: true`，超出差额自动抹平预算，账目毫厘不爽。 |
| **痛点 2** | **部分成交无法拆单**<br>（挂 1,000 股实成 400 股，系统无法拆单，要么全改要么未成股数凭空蒸发） | **引入自动派生拆单引擎 (`Derive Step`)**：<br>录入实成 400 股后，原预案层锁定为 `【400股 · 已成交锁定(exec)】` 并生成只读交易流水；剩余 600 股自动派生为 `【600股 · 衍生子批次继续守候】`。若后续股价大涨触发**做飞警戒线**，系统主动提示人工确认终止接单，转为被动锁利。 |
| **痛点 3** | **卖出无 exec 标记结构，AI 重新生成时有覆写风险** | **统一全生命周期 Step 数据结构 (`Universal Step Model`) + 只读日志层保护**：<br>① `sellSteps` 与 `buySteps` 享有一模一样的 `exec` 凭据结构（记录成交价、真实交割股数、锁利金额）；<br>② **数据所有权物理隔离**：AI 生成的永远只写入虚拟草稿 `blueprintPlan`，而真实的 `tradeLogs` 存储在**绝对只读集合**中。AI 无论重新生成 100 次方案，也绝对无法覆写或抹除真实成交记录！ |
| **痛点 4** | **风控只是弹窗软约束**<br>（跌破失效线点确定仍能买入，临场上头随意下移止损线，最终陷入死扛深渊） | **从「UI软弹窗」升级为「引擎级断路器 (`Hard Circuit Breaker`)」**：<br>① **失效线底层硬阻断**：现价 < 失效线（如 ¥22.50）时，代码底层直接将所有买单提交入口物理禁用锁死，杜绝临场手痒；<br>② **单向棘轮原则 (`Ratchet Principle`)**：止损线代码限制**只许向上抬高锁利，严禁向下滑移死扛**；<br>③ **48小时防追高冷静期**：单日大涨时冻结临时追高挂单，强制自省冷却。 |
| **痛点 5** | **历史成交躺在日志里，不会自动回流 AI Prompt**<br>（实盘与 AI 严重割裂，AI 依据空壳模板闭门造车） | **实盘交易日志自动装配反哺飞轮 (`Prompt Ingestion Flywheel`)**：<br>大模型提示词组装器自动从 `tradeLogs` 中抓取**真实加权成本 (WAC)、已消耗真实预算、做T累计降本实绩**作为不可辩驳的前置客观约束注入 Prompt，让外部 AI（DeepSeek / Claude）每次出方案时都基于真实实盘数据说话！ |

## 🎨 中国股市红涨绿跌规范与视觉标准体系

本系统严格遵守**中国 A 股国家金融标准配色及交易直觉**：

- 🔴 **红色系（Rose / Red / Crimson / #f43f5e / #ef4444）**：
  - **上涨、浮盈、做T正收益、盈利百分比**（如 `+0.38%`、`+¥14,200`、`年化CAGR +18.4%`）；
  - **阶梯止盈层（高抛越涨越卖）、顺滑正滑点、已锁盈利**；
  - **绝对硬失效止损线**（底部警戒断路红光，破位坚决止损认错）。
- 🟢 **绿色系（Emerald / Green / #10b981 / #34d399）**：
  - **下跌、浮亏、跌幅百分比**（如 `-3.39%`）；
  - **分批接货伏击层**（越跌越买，向下倒三角吸纳）；
  - **有利低吸负滑点、低波红利压舱仓、纪律合格评分**。
- 🟡 **琥珀金与明黄（Amber / Gold / Brand / #f59e0b）**：
  - **核心底仓锁定中枢**（双向钻石菱形最宽处 95% 橙金柱）、品牌主色、当前执行决策状态徽标。
- 🔵 **科技冷静蓝（Sky / Blue / #38bdf8）**：
  - **伏击备用现金池、突破加码追档、DRIP 股息复利注水**。

## 🚀 核心功能模块与使用说明

1. **组合 (Portfolio) · 全局资产大盘**
   - 净资产估值双账实时核算、年化 CAGR、累计做T降本收益。
   - **纯原生 SVG 净值走势图**（近 30 日无外部依赖绘制）与**仓位环形图**（核心仓 55% / 压舱仓 32% / 现款 13%）。
   - 个股仓位池支持一键展开/折叠明细，直接穿透至标的决策看板。

2. **标的 (Plan) · 决策指挥部与双向钻石菱形**
   - **三核心裁决卡片**：① 当前裁决状态 ｜ ② 下一关键买点触发 ｜ ③ 绝对失效硬底线（单向棘轮）。
   - **双向收敛钻石菱形挂单图谱**：
     - ▲ 阶梯止盈层（红色高抛，向上收敛）；
     - ■ 核心底仓基座（橙金 95% 最宽中枢）；
     - ▼ 分批接货层（绿色倒三角，向下收吸）；
     - --- 绝对失效硬底线（虚线断路器，破位全清）。
   - **最坏情况压力测试 (Worst-Case)**：极限破位最大回撤预先锁定。

3. **分析 (Analysis) · AI 6维研判与方案收敛**
   - **6 维客观事实研判卡片**（技术面、财务面、行业景气、对标龙头估值、情绪筹码、证伪底线）＋ 自定义条件扩展。
   - **Prompt v5 官方提示词一键生成**：植入 Why Box 灵魂买入理由。
   - **外部大模型 (DeepSeek / ChatGPT) 智能四段解析**：
     - 档N ➔ 向下正金字塔接单；
     - 追N ➔ 向上右侧突破跟进；
     - 止损 ➔ 单向棘轮硬防线；
     - 盈N ➔ 阶梯获利减仓。

4. **执行 (Execution) · 券商实扣流水与硬断路闸门**
   - **现实三大事件闸门**：`放行 (Unlock)`、`熔断 (Kill)`、`复盘 (Review)`。
   - **券商实扣流水倒推与滑点精算**：
     - 输入银证转出总额，全自动倒推印花税（买入免征、卖出0.05%）、万2.5佣金（保底¥5）、过户规费（万0.1）与真实成交滑点。
   - **知行合一纪律执行日志**：记录每一笔计划内履约。

5. **手记 (Thesis & DRIP) · 股息复利与多端数据同步**
   - **除权除息等比平移与 DRIP 测算**：分红除权产生价格跳空缺口时，一键全自动等比向下平移所有网格与硬止损线，彻底杜绝除权误打止损；支持现金分红一键注水下一买单。
   - **长线心智手记 (Thesis Journal)**：沉淀商业模式与纪律自查。
   - **GitHub 自动无感双向同步 (`data.json`)**：
     - 绑定个人 Fine-grained PAT 即可实现 Mac、iPhone、iPad 之间多设备全自动云端对齐（启动拉取 + 本地变更后台自动 commit 推送）。
   - **本地 PWA 离线沙盒自持**：一键导出/恢复完整 JSON 灾备包、彻底清空或恢复官方示例。
